# Claude Code プライバシーポリシー

## このアプリについて

「Claude Code」は個人の自動化ツールです。Google Tasks を読み書きするためだけに使います。利用者は本人1名で、業務や第三者向けのサービスではありません。

## 取得するデータ

Google Tasks のタスクタイトル・期日・メモ・完了状態を取得します。それ以外の Google アカウント情報は取得しません。

## データの扱い

取得したデータは本人のPC内でのみ処理します。外部のサーバーへ送信したり、保存したりすることはありません。AI モデルの学習に使うこともありません。

## データの削除

いつでも Google アカウントの「サードパーティのアクセス」設定からこのアプリのアクセス権を取り消せます。取り消すとデータの取得は行われなくなります。

## Summary (English)

"Claude Code" is a personal automation tool used by a single individual to read and write their own Google Tasks (title, due date, notes, completion status). All data is processed locally on the user's PC only; nothing is sent to or stored on any server, shared with third parties, or used for model training. Access can be revoked anytime via Google Account's third-party access settings. Contact: this repository's Issues. Last revised: 2026-09-20.
